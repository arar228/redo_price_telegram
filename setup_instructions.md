# Инструкция по настройке бота в Telegram канале

## Проблема
Ошибка: "Need administrator rights in the channel chat"

## Решение

### Шаг 1: Добавьте бота в канал
1. Откройте ваш канал "Redo Price" в Telegram
2. Нажмите на название канала вверху
3. Выберите "Управление каналом"

### Шаг 2: Добавьте бота как администратора
1. В разделе "Управление каналом" найдите "Администраторы"
2. Нажмите "Добавить администратора"
3. Найдите вашего бота по имени или токену
4. Добавьте бота

### Шаг 3: Настройте права бота
Обязательно включите следующие права:
- ✅ **Отправка сообщений** (Post Messages)
- ✅ **Редактирование сообщений** (Edit Messages) - опционально
- ✅ **Удаление сообщений** (Delete Messages) - опционально

### Шаг 4: Проверьте настройки
Убедитесь, что:
- Бот добавлен как администратор
- У бота есть право "Отправка сообщений"
- Канал не заблокирован

### Шаг 5: Перезапустите бота
После настройки прав запустите бота снова:
```bash
python price_tracker.py
```

## Альтернативный способ (если канал приватный)

Если канал приватный, вы также можете:
1. Сделать канал публичным
2. Или добавить бота через прямую ссылку: `https://t.me/ваш_бот_username?startgroup=`

## Проверка работы

После настройки бот должен:
1. Успешно подключиться к каналу
2. Начать отправлять сообщения каждую минуту
3. Показывать сообщение "Price update sent successfully"

Если проблемы продолжаются, проверьте:
- Правильность токена бота
- Правильность ID канала
- Права администратора в канале
