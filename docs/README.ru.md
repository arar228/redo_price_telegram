# REDO Price Tracker

[English overview](../README.md)

Python-воркер получает данные DexScreener, формирует сводку цены и изменений за несколько периодов и отправляет сообщение в Telegram. Основная логика расположена в `RedoPriceTracker` внутри `price_tracker.py`.

Для подготовки нужны отдельное Python-окружение, зависимости из `requirements.txt`, собственный бот и тестовый канал с разрешением на публикацию. Имена настроек: `BOT_TOKEN`, `CHAT_ID`, `TOKEN_CA`, `DEXSCREENER_API`, `DEXSCREENER_URL`, `UPDATE_INTERVAL`.

Текущий `config.py` читает окружение процесса. Файл `.env` сам по себе не загружается: переменные должен передать launcher, shell или менеджер сервиса. `python price_tracker.py` начинает работу с внешним API и отправку сообщений.

[setup_instructions.md](../setup_instructions.md) сохранён как существующая инструкция; при восстановлении следует учитывать уточнение о загрузке окружения и совместимость Python с закреплёнными зависимостями.

Обзор исходников выполнен 2026-09-07. Реальная отправка сообщений, актуальность данных провайдера и активное размещение в этом проходе не проверялись.
